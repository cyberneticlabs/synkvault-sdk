# Python SDK

Official Python SDK for the SynkVault Partners API.

**Status**: In development

## Planned Features

- Full resource support (Health, Orgs, Ontology, Knowledge, Ingest, Documents, Chat)
- Streaming Chat with async/await support
- Type hints and IDE autocomplete
- Comprehensive error handling
- Sync and async API clients

## Requirements

- Python 3.10+
